# Equii corporate website
Static responsive site, no dependencies or build required. Repository: `Tomhaxley/Equii.Website`.

## Local preview
Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Deploy to EUKhost
Upload the contents of this directory to the document root for equii.co.uk (typically public_html for a Linux shared hosting primary domain). Verify the domain mapping, enable HTTPS, and test links on mobile and desktop.

## Before launch
- Confirm the final EquiiTrack public URL. The current product detail link points to the previously used development hostname, not a verified public product website.
- Replace illustrative AI-generated prototype imagery with real hardware and horse photography when available. Product renderings do not represent final hardware.
- Confirm product names, development statuses and brand assets. EquiiFit is a concept; EquiiJump is the proposed timing system name.
- Add contact details and any required legal/privacy information once company details are confirmed.
- No tracking, forms, cookies or third-party libraries are included.

## Branches
`main` is reserved for production releases. `dev` is the working branch.
